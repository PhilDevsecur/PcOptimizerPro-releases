# PC Optimizer Pro — installateurs

Ce dépôt ne contient que les versions publiées de PC Optimizer Pro (le code source est privé).

**Installer :** ouvrez [la dernière version](https://github.com/PhilDevsecur/PcOptimizerPro-releases/releases/latest) et téléchargez `PcOptimizerPro-Setup-x.y.z.exe`.
Windows SmartScreen peut afficher un avertissement (exécutable non signé) : « Informations complémentaires » → « Exécuter quand même ».

**Mises à jour :** automatiques. L'application vérifie au démarrage puis toutes les 4 h, télécharge en arrière-plan et installe à la fermeture.
